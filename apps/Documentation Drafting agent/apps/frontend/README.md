# Documentation Drafting Agent — Nested Frontend Workspace

This folder contains the nested frontend workspace for the Documentation Drafting Agent.

## Run

```bash
cd "apps/Documentation Drafting agent/apps/frontend"
pnpm install
pnpm run dev
```

Default local URL: `http://localhost:3000`.

When running via Docker, use the infra stack in:

- `infra/Documentation Drafting agent`

and open:

- `http://localhost:13100`
